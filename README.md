# lc-docs

Public, published copies of La Chamana team documents.

Served at https://bothventures.github.io/lc-docs/

This repo holds **only** finished documents meant to be shared. The working
repo (`lc-chaman`) stays private: it carries prospect contact data, integration
access maps and internal memos that must never be published.

Source of truth for each file is `lc-chaman/docs/`. Copy here to publish.
